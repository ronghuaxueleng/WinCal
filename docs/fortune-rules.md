# 运势规则 v3

WinCal 使用本地四柱排盘，结合月令、通根及大运／流年／流月／流日生成可复现的评分。历法和起运有公开实现可校验；百分制权重由本项目定义，不代表传统命理的统一标准，也不复现易奇评分。

## 排盘

- 公历出生日期、可选小时和分钟，均按北京时间解释，不随电脑时区换算，不作真太阳时校正。
- 立春精确时刻换年，十二个“节”的精确时刻换月；零点换日。23:00～23:59 的时干按次日日干起算，对应 lunar-python sect 2。
- 未填出生时间时，以中午确定年月柱，只使用三柱，不计算大运。性别未填时同样不计算大运。
- 出生日期支持 1900～2100 年；交节表包含 1899～2101 年。流年、流月及当前大运按所选日期北京时间中午确定。

`native/tools/generate-fortune.py` 使用 `lunar_python==1.4.8` 生成交节表、179 组四柱参考和 360 组男女起运参考；程序运行不需要 Python 或网络。

## 月令、通根和扶抑

五行顺序为木、火、土、金、水。藏干按原库顺序排列，一藏干占 100%，两藏干为 70:30，三藏干为 60:30:10。

1. 季节元素：寅卯木、巳午火、申酉金、亥子水、辰戌丑未土。相对季节元素，旺、相、休、囚、死系数分别为 150%、120%、90%、70%、50%。这些数值是本项目约定。
2. 每个可见天干查找所有已知出生地支中的同五行藏干作为根。同柱根按 100%，相邻柱按 90%，更远按 80%，按藏干占比累计通根力量。该值用于展示和有根判断；无根天干另折为 70%，有根按 100%。
3. 五行力量采用天干基础 40、地支基础 100。相对日柱的位置权重：年柱 80%、月柱和时柱 90%、日柱 100%。每项再乘季节系数；地支按藏干拆分，天干乘上述有根／无根系数。各项整数截断后求和。
4. 日主同五行与生我五行的力量占比大于 55% 为偏强，小于 45% 为偏弱，其余中和。偏强时生扶五行 -8、克泄耗 +8，偏弱相反。中和时，低于总量五分之一的五行 +6，高于者 -6，恰好相等为 0。
5. 展示月支本气对应的“当令十神”，不据此判完整格局。生扶占比至少 85%，或至多 15% 且日主无根时，提示极端命局，不自动判从格。

调候单独计算：亥子丑月火 +4、水 -3；巳午未月水 +4、火 -3；戌月水 +2、辰月火 +2。这里只是寒暖燥湿辅助，不能等同完整调候体系。

## 大运

填入性别和出生时间后，按阳男阴女顺排、阴男阳女逆排。顺排取出生后下一个节，逆排取出生前或恰好出生时的节。

起运采用 lunar-python 的 Yun sect 2 分钟法：出生与交节时刻分别向下取整到民用分钟，再求间隔。4320 分钟折一年，余数每 360 分钟折一月，再每 12 分钟折一日，最终每分钟折两小时。依次将年、月、日、小时加到出生时刻；加年或月遇不存在的日期时取当月最后一天。

准确起运时刻起，以月柱顺／逆推一位作为第一运，此后每满十个公历周年换运；尚未起运不计大运。起运时刻及干支序列与参考库校验；十周年换运边界是本项目的明确定义，不等同该库按年龄、公历年列示的大运年段。

## 层次评分

按大运、流年、流月、流日顺序叠加，每层均对照出生地支及已加入的上层地支。

- 五行项 =（该层天干扶抑喜忌 × 40 + 地支藏干扶抑喜忌按总量 100 加权）÷ 140。调候项采用同样算法。
- 十神名称由日主与该层天干的五行、阴阳关系确定；十神项 = 天干扶抑喜忌 ÷ 2。同五行的正偏十神不额外区分数值。
- 每对地支关系按首个匹配取分：自刑 -3、六合 +6、六冲 -8、刑 -5、害 -4、破 -3、半三合 +3，其余 0。自刑仅辰午酉亥；三刑按成对关系简化。累计地支项限于 ±20。
- 加入本层后新凑齐三合或三会，按对应元素扶抑喜忌 ÷ 2 计引动；原本已齐全不重复计。三合为申子辰水、亥卯未木、寅午戌火、巳酉丑金；三会为寅卯辰木、巳午未火、申酉戌金、亥子丑水。引动合计限于 ±8，不判合化。
- 层总分 = 限幅（五行 + 地支 ÷ 2 + 十神 ÷ 2 + 调候 + 引动，±30）。大运贡献为层总分 ÷ 2，流年为 ÷ 3，流月为 ÷ 2；三者相加限于 ±20，作为背景项。

流日各项代入：

```text
人际 = 60 + 背景 + 日五行 + 日地支 + 日引动
行动 = 60 + 背景 + 日五行 × 2 + 日十神 + 日地支 ÷ 2 + 日调候 + 日引动
节奏 = 60 + 背景 + 日五行 + 日地支 ÷ 2 + 日调候
综合 = 三项平均，四舍五入
```

除法向零取整；三项分别限于 5～95。未来 15 天使用同一命盘逐日计算，无随机数或人工校准点。点击“依据”可查看命盘、通根力量、各层贡献和流日公式。
